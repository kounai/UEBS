# UEBS
"يُعد هذا المشروع الجامعي خطوة أساسية ومهمة في مسيرتي الأكاديمية بتخصص تقنية المعلومات، حيث تم تقديم وتطوير النظام بجهود مشتركة مع فريق العمل، وركز على تقديم حلول عملية وموثوقة. بفضل الله، توجت هذه الجهود بحصول المشروع على المركز الثاني في التقييم النهائي، مما يعكس جودة فكرة المشروع وإتقان تنفيذه."
